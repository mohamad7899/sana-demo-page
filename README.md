## 📌 درباره پروژه

**SanaDemo** یک پروژه مستقل و آموزشی در زمینه طراحی و توسعه وب است که با هدف یادگیری HTML و CSS و تجربه ساخت رابط کاربری مدرن ایجاد شده است.

این پروژه با الهام از سبک Neon و Glassmorphism طراحی شده و دارای ساختار چندصفحه‌ای است.

## ✨ امکانات

| ویژگی | توضیحات |
|---|---|
| 🎨 طراحی Neon | جلوه‌های نوری و رنگ‌های نئونی |
| 🌙 Dark Theme | رابط کاربری با تم تاریک |
| 📱 Responsive | سازگار با موبایل و دسکتاپ |
| 🧭 Multi-Page | ساختار چندصفحه‌ای |
| 💎 CSS Effects | انیمیشن‌ها و جلوه‌های بصری |
| 🔗 External Link | دسترسی به وب‌سایت رسمی ثنا |
