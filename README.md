## 📌 درباره پروژه

SanaDemo یک پروژه تمرینی در زمینه طراحی و توسعه وب است که با هدف یادگیری و تجربه ساخت رابط کاربری مدرن ایجاد شده است.

این پروژه از طراحی تاریک، جلوه‌های نئونی و ساختار چندصفحه‌ای استفاده می‌کند.

## ✨ امکانات

- 🎨 طراحی مدرن با سبک Neon
- 🌙 رابط کاربری Dark Theme
- 📱 طراحی واکنش‌گرا (Responsive)
- 🧭 ساختار چندصفحه‌ای
- 💎 جلوه‌های بصری و انیمیشن‌های CSS
- 🔗 دسترسی مستقیم به وب‌سایت رسمی ثنا
